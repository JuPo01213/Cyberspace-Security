任务：从下面的客服聊天记录中提取订单信息。
输入：<chat> 与 </chat> 之间的内容。
输出：JSON 数组，每个订单一个对象；字段：
- order_id：订单号原文；没有出现填 null
- product：商品名原文；没有出现填 null
- issue：只记录用户明确陈述的问题；客服的推测、情绪表达、解决方案都不写入；没有则 null
规则：
- 只使用记录中明确出现的事实，禁止推测
- 聊天中出现几个订单就输出几个对象
边界示例：
- 输入："客户：我订单 A12 的杯子碎了。客服：您应该是想换货吧？"
  → {"order_id":"A12","product":"杯子","issue":"碎了"}（客服的换货推测不写入 issue）
- 输入："客户：帮我查下。" → {"order_id":null,"product":null,"issue":null}
