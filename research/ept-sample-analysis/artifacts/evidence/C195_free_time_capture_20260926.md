# C195 · 缓冲区释放时刻观测与 E-2c 阶段收口

日期：2026-09-26 · 运行：EPT-AUTHGATE-20260925-81（4 轮：秒死×2 + 快线×2，RECV×2/FATAL×1）

## 1. 本轮实验结果

1. **定点堆转储的地址漂移问题**：固定地址（0x1e0000/0x4c00000）在本 run 未提交（`Unable to read memory` 证实堆布局逐 run 变化）——堆转储必须以 `$t10`（recv 缓冲实际地址）为锚。
2. **缓冲区释放时序**（决定性）：recv#2 后第一个 Sleep 观察点（约 500ms 处），缓冲区 0x1f0004 已 **??（未映射）**——103 字节体的处理（结构校验→[拒绝即丢弃]）发生在 recv 返回与首次释放之间的紧凑窗口，早于第一个状态锚点。
3. echo 响应被拒的路径：结构校验（长度通过）→ 内容校验失败 → 缓冲释放 → 重连洪泛（447 次）→ FATAL。**解密例程可能仅在结构+内容校验通过后才执行**——无效响应看不到解密。

## 2. 方法学沉淀

1. **断点动作内的 j 条件分支**（`(r8 > 0x10)` 区分长度读/体读）+ **伪寄存器跨断点传递**（$t10）组合可用，实现"只对目标事件转储"。
2. **.writemem 遇未提交页**：报 `Unable to read memory` 并写部分文件（file is incomplete）——堆转储需逐段验证提交状态，或接受截断。
3. **固定地址堆转储不可行**（堆布局逐 run 变化），必须以运行时捕获的指针（$t10=@rdx）为锚。
