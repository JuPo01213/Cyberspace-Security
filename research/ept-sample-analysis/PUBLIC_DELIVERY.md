# PUBLIC_DELIVERY — 本条目的收录范围、脱敏与诚实度声明

本文件说明 `research/ept-sample-analysis/` 这一条目**收录了什么、没有收录什么、改了什么**，以及当前结论闭合到哪一步。引用本条目之前应先读这一页。

## 1. 这是什么

对一份**恶意样本**（`EPT专业游戏维修工具箱V5.1.exe` 及其下发的核心组件 `Hardware.exe` / genB）的逆向分析工作记录：静态面重建、受控 VM 动态实验、授权与联网校验闸门定位，以及贯穿全程的仪器失效编年。

分析在隔离 VM 内进行，宿主只做编排、取证拷贝与证据整理。

## 2. 收录范围

本条目**只收录文本与小型证据件**：

| 收录 | 内容 |
|---|---|
| `writeup/` | 分篇交付正文（7 篇 .md） |
| `artifacts/evidence/`、`artifacts/deprecated/` | 证据件与作废件说明 |
| `runs/` | 每轮实验的脚本、结构化产物、文本日志（已剔除大转储） |
| `method/`、`patches/`、`config/` | 方法论、可复现脚本、可回滚补丁 |
| `archive/` | 拆分前的冻结单文件原件 |
| 根级文档 | `README.md`、`LAYOUT.md`、`RUN_MANIFEST_genB.md`、`REORG_MANIFEST.md` 等 |

## 3. 明确排除（未随本条目发布）

**样本字节与其派生物一律不含在内**，包括：

- 样本本体与解包树（`sample/`、`*_extracted/`、`unpack/`）；
- 内存转储、解密镜像、进程映像副本（`*.dmp`、`*.bin`、`*.exe`、`*.zip`）；
- 抓包文件（`artifacts/captures/pcap/`）；
- 反汇编器工程对象与中间物。

这些材料的完整性信息（SHA-256、来源路径、派生步骤）保留在文本证据件中；需要原始字节复现时，按 `writeup/05-conclusions-and-ledger.md` §5.4 的说明在**自有样本副本**上重做。

## 4. 脱敏动作

发布前对全部文本执行了一遍替换，规则与目标仓库 `AGENTS.md`《脱敏》一致：

| 类别 | 处理 |
|---|---|
| 内嵌校验 token 字面量 | → `<REDACTED_EMBEDDED_VERIFY_TOKEN>` |
| 宿主绝对路径（各分隔符形式、bash/WSL 形式） | → `<HOST_PATH>` 前缀 |
| 真实用户目录 | → `<USER>` |
| 宿主机器名 | → `<HOST_NAME>` |
| 靶机标签与账号 | → `<VM_LABEL>`、`<VM_USER>` |
| 与本样本无关的宿主 VM 工程名 | → `<OTHER_VM_LABEL>` |
| 私有网段地址 | → `<PRIVATE_IP>` |

**保留**的 `C:\Windows\...`、`C:\ept_core\...`、`C:\ept_obs\...` 等是**靶机内部**可复现位置，不是宿主环境信息，因此按证据价值保留原样。样本自身硬编码的输出路径同理——那是被分析对象的行为特征，属于分析结论的一部分。

## 5. 证据诚实度声明

本条目严格区分：**观察**（在盘证据可复现）／**推断**（由观察推出的解释）／**未决**（尚未取得证据）。

**当前目标级状态（截至最后一次提交）：**

| 判据 | 状态 |
|---|---|
| 解码 seam 在真实目标进程中发生（`target_native_return==0x1`） | `NOT_OBSERVED` |
| caller `+0x80` 差分字节数（`target_caller_diff_bytes>0`） | `NOT_OBSERVED` |
| RC06 进入 | `NOT_OBSERVED` |
| 解码后自然行为 | `NOT_OBSERVED` |
| 自然授权 | **从未观测到** |

即：**本地授权链与解码 seam 的机制已重建，但“真实样本在自然授权下越过解码并产生后续恶意行为”尚未取得端到端证据。**

项目内部把手段分为三类，结论必须逐轮标注：

```text
自然授权 (natural authorization)          样本自身算法独立判定成功并继续
受控放行 (gate reversal, controlled)      外部最小可回滚改动，使样本进入后续路径
伪造授权 (forged authorization)           直接写状态全局 / patch 成恒成功（禁止冒充自然授权）
```

**把校验判定从“否”改成“是”并触发后续动作，不构成自然授权**——校验通过时本该由样本自身算法同时生成的派生状态（解析字段、会话/许可信息、机器绑定结果）并不存在，后续行为可能缺失或走偏。实测证据：强制放行后仍出现 `IsLogin=0`、`GetServerOption=-3`，随后 `FatalExit`。

## 6. 安全边界（复现前必读）

- 样本**只在隔离 VM 内执行**，宿主从不执行样本字节；
- 实验前必须存在可回滚快照；补丁与探针仅作用于可回滚副本，原始样本只读；
- 内嵌 token 不解码；
- **不连接样本指向的外部校验域名**；
- 实验盘只读挂载。
