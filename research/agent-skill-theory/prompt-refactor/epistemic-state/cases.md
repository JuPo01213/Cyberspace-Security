# 认识状态 Few-shot

## 肯定后件

已知“如果服务崩溃，则健康检查失败”；现在观察到健康检查失败。

错误：服务已经崩溃。

正确：服务崩溃是候选解释之一；仅由后件不能反推前件。

## 403 不是根因

观察：请求返回 HTTP 403。

正确状态：
- “返回 403”是观察；
- “权限不足”是候选解释；
- 在认证、网关策略、来源限制等替代解释未排除前，不升级为已确立根因。

## 未发现不等于不存在

快速搜索没有找到成熟工具。

错误：没有成熟工具。

正确：当前只知道“这次搜索未发现”，不能自动得到“不存在”。

## 局部测试不支持全局结论

修改后 Linux 测试通过，目标还包括 Windows 中文路径。

错误：问题已经完全修复。

正确：Linux 覆盖范围内的行为受到支持；Windows 中文路径仍未验证。

## 时间顺序不等于因果

升级依赖后程序开始变慢。

错误：升级一定导致性能下降。

正确：升级与变慢存在时间关系；因果关系仍需证据排除其他关键变化。

## 冲突状态

日志 A 显示任务成功，数据库状态显示目标记录未写入，且暂时无法解释差异。

正确：保留冲突，不任选一个来源恢复“成功”或“失败”的单一叙事。

## 行动不证明假设

怀疑缓存导致旧结果，于是清空缓存后重试。

即使该行动是合理探索，也不能因为“已经按缓存问题处理”就把缓存问题升级为事实；只能根据重试产生的新观察更新认识状态。
