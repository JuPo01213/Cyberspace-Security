# 能力状态 Few-shot

## 工具存在但未就绪

系统中安装了某 CLI，但当前缺少认证配置。

正确状态：
- 能力存在；
- 当前不可直接使用；
- “完成认证配置”是使其就绪所需前提。

## 缺少特定工具不等于能力缺口

任务需要解压 ZIP，没有用户最初点名的工具，但系统已有另一可靠解压能力。

错误：目标能力缺失。

正确：特定工具缺失，但“解压 ZIP”能力并不缺失。

## 已有能力只覆盖局部

现有上传模块支持普通文件，但缺少目标格式所需的校验。

正确：保留“已有上传能力”以及“校验能力缺口”，不把整个上传能力视为不存在，也不假装已经完整满足目标。

## 可获得能力

当前没有所需解析器，但官方库可安装且与环境兼容。

正确：当前能力缺失，同时存在明确的可获得能力；是否安装由执行控制决定。

## 组合能力需要接口成立

工具 A 可以导出数据，工具 B 可以处理另一种格式，但两者格式并不兼容。

错误：A+B 已经形成完整处理链。

正确：组合接口尚未成立，因此链路能力仍存在缺口。

## 模型手工能力与专用工具同时存在

模型可以人工比较两个大文件，环境中也有可靠 diff 工具。

正确：两种能力都存在；能力状态不在这里决定最终使用哪一种。

## 能力状态会变化

任务开始时缺少运行环境，随后环境安装完成并通过基本检查。

正确：更新能力状态，不继续沿用“环境缺失”的旧判断。
