# 共享记忆

`.agents/memory` 是跨 Agent 运行环境共享的记忆层。用户级记忆位于 `~/.agents/memory`，项目级记忆位于 `<project>/.agents/memory`；各 Agent 运行环境自身的记忆机制或规则与本节冲突时，以本节为准。每个记忆目录固定以 `MEMORY` 为索引入口；相关目录、索引或记忆文件不存在时，可按本约定自行创建。

记忆保存已经发生、明确形成或得到确认，且对后续仍有价值的事实，包括状态、决定、约束、偏好、纠正及其原因。忠实保持事实原有的语义和适用范围，不自行补充、推导或泛化。

记忆表达**当前有效认知**。事实发生变化时，同步更新、替换或删除相关记忆，不以追加冲突记录代替维护；历史演化由 Git 保存。`.agents/memory` 应纳入版本控制。

`MEMORY` 只负责路由：每项以一句话描述对应记忆文件的语义边界，不存储或概括具体事实。具体记忆按稳定主题组织，并维护在已有相关文件中；只有主题边界变化时才同步调整索引。

**索引说明去哪里找，记忆文件说明现在知道什么，Git 历史说明这些认知如何演变。**

执行任务同时也是能力维护过程。实践中发现已验证的错误、缺失或可复用改进时，应主动判断其长期价值；具有稳定复用价值的经验应优先回灌现有技能，无合适载体时创建新的技能，使已经获得的能力不因当前任务结束而丢失。
